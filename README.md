### คำอธิบายรายวิชา

ศึกษาและฝึกปฏิบัติการเกี่ยวกับการแทนข้อมูล โครงสร้างและการออกแบบข้อมูล แบบอาร์เรย์ สแต็ก คิว ลิงค์ลิสต์ ต้นไม้ กราฟ การจัดเรียงข้อมูล การค้นหาข้อมูล การวิเคราะห์ขั้นตอนวิธี

*Study and practice of data representations and data structures (array, stack, queues, linked lists, trees and graphs), sorting, searching, analysis of algorithms.*

### จุดมุ่งหมายของรายวิชา

1. เพื่อให้นักศึกษามีความรู้ความเข้าใจเกี่ยวกับการแทนข้อมูลในหน่วยความจำ แนวคิดชนิดข้อมูลนามธรรม และการออกแบบโครงสร้างข้อมูล
2. เพื่อให้นักศึกษาสามารถวิเคราะห์ประสิทธิภาพของขั้นตอนวิธีด้วยสัญกรณ์เชิงเส้นกำกับ และเลือกขั้นตอนวิธีที่เหมาะสมกับปัญหาได้
3. เพื่อให้นักศึกษาสามารถออกแบบและเขียนโปรแกรมโครงสร้างข้อมูลแบบเชิงเส้น ได้แก่ แถวลำดับ รายการโยง กองซ้อน และแถวคอย ได้
4. เพื่อให้นักศึกษาสามารถออกแบบและเขียนโปรแกรมโครงสร้างข้อมูลแบบต้นไม้ ต้นไม้ค้นหาแบบทวิภาค ต้นไม้สมดุล และฮีป ได้
5. เพื่อให้นักศึกษาเข้าใจการแทนกราฟ และประยุกต์ขั้นตอนวิธีการท่องกราฟ เส้นทางที่สั้นที่สุด และต้นไม้แผ่ทั่วที่น้อยที่สุดได้
6. เพื่อให้นักศึกษาสามารถเปรียบเทียบและเขียนโปรแกรมขั้นตอนวิธีการจัดเรียงข้อมูลและการค้นหาข้อมูล รวมทั้งตารางแฮชได้
7. เพื่อให้นักศึกษาฝึกปฏิบัติเขียนโปรแกรมภาษา C ทดสอบ วัดประสิทธิภาพ และเลือกใช้โครงสร้างข้อมูลแก้ปัญหาทางวิศวกรรมคอมพิวเตอร์ได้

### เครื่องมือและสภาพแวดล้อมที่ใช้

- เครื่องคอมพิวเตอร์ห้องปฏิบัติการ 1 เครื่องต่อนักศึกษา 1 คน
- ระบบปฏิบัติการ Microsoft Windows 10/11 หรือ Ubuntu Linux 24.04 LTS (นักศึกษา) และ macOS (ผู้สอน)
- ชุดเครื่องมือพัฒนาโปรแกรมภาษา C มาตรฐาน C11 ได้แก่ MinGW-w64 GCC (MSYS2) บน Windows, gcc บน Linux, clang บน macOS ร่วมกับ gdb, make, Visual Studio Code, Git และ Python 3 สำหรับพล็อตกราฟ
- เครื่องมือแสดงภาพโครงสร้างข้อมูล VisuAlgo เครื่องฉายภาพ (Projector) และระบบจัดการเรียนรู้ออนไลน์
